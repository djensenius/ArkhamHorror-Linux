# Security policy

## Supported versions

Until releases begin, only the latest `main` branch is supported. Security
fixes are not backported to foundation branches or old AppImage artifacts.

## Reporting a vulnerability

Use
[GitHub private vulnerability reporting](https://github.com/djensenius/ArkhamHorror-Linux/security/advisories/new).
Do not open a public issue for suspected credential exposure, unsafe URL or
archive handling, authentication bypass, packaging compromise, or private-data
disclosure.

Include the affected distribution, display environment, build, reproduction
conditions, expected impact, and any suggested mitigation. Remove server
tokens, passwords, private game data, and personally identifying information
from all attachments.
